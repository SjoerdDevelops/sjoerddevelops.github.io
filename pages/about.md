# Hi, I'm Sjoerd

I am a Robotics Software Engineer all about developing solutions that are not just advanced, but truly valuable and easy to use. I'm very curious by nature, with a passion for Software Development, Robotics, and Human-Machine Interaction. Excels at untangling multifaceted problems by stepping back to see the bigger picture. Enjoys applying design patterns to create scalable, reliable software modules. Always eager to learn, from programming concepts and emerging development tools to 3D printing and prototyping.

# Skills and Tools
I have programming experience in various languages, including C++ and C\# for developing simulations and software modules, Python for data analysis and machine learning, and HTML/CSS/TypeScript for web applications linked with PostgreSQL databases. Whether it is implementing simulations, haptic feedback algorithms, or drivers for a robotic gripper, I like to break software down into reusable modules by considering code architecture and design patterns. In doing so, I use tools like Git for version control, Docker for containerization, and various (coverage) testing frameworks.

## Hobby's
I am always eager to learn and broaden my skill set. In fact, I spend most of my personal time exploring new technologies, learning and creating.
