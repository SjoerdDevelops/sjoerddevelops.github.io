# About me
I am a Robotics Software Engineer all about developing solutions that are not just advanced, but truly valuable and easy to use. I'm very curious by nature, with a passion for Software Development, Robotics, and Human-Machine Interaction. I excel at untangling multifaceted problems by stepping back to see the bigger picture and enjoy applying design patterns to create scalable, reliable software modules. I'm always eager to learn, from programming concepts and emerging development tools to 3D printing and prototyping.

# Skills and Tools
I have programming experience in various languages, including C++ and C\# for developing simulations and software modules, Python for data analysis and machine learning, and HTML/CSS/TypeScript for web applications linked with PostgreSQL databases. Whether it is implementing simulations, haptic feedback algorithms, or drivers for a robotic gripper, I like to break software down into reusable modules by considering code architecture and design patterns. In doing so, I use tools like Git for version control, Docker for containerization, and various (coverage) testing frameworks.

## Hobbies
I spend most of my personal time exploring new technologies, learning and creating.

### Learning
Whenever I want to learn a new skill, I turn to YouTube tutorials and other online resources. At home or whilst commuting I regularly watch videos about new programming concepts, emerging development tools, or upcoming language features. It's not all related to software development or robotics either. Whenever I encounted a task I'm unfamiliar with, I use online resources to learn how to tackle it. 

I enjoy applying the skills I acquire in personal projects. During my brief stint as a high school mathematics teacher, I developed my own web application using `php` that allowed my students to watch tutorial videos I had created for them directly on their phones.

In my current job, I noticed that resource planning across projects sometimes led to colleagues being either over- or underutilized. To adress this issue, I learned `PyQt` in my free time and developed a small application to consolidate project planning files.
